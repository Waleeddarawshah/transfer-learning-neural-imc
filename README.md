# Transfer Learning for Neural Network Internal Model Control of Chemical Processes

This repository contains the code developed during Waleed Al-Darawshah's Bachelor End Project research. It accompanies the final report submission and provides readers with additional context, implementation details, and reproducible materials supporting the project's methodology, analysis, and final findings.

As discussed in the final report, this research project consists of five main components: (1) Open-Loop Simulation, (2) Model Training, (3) Controller Training, (4) Fine-Tuning, and (5) Closed-Loop Simulation. Correspondingly, five main codes were developed to implement these components. More information about each code is presented below.

## (1) Open-Loop Simulation

The objective of this component is to generate data representative of the system under investigation, which in this project is a Continuous Stirred Tank Reactor (CSTR). The output consists of six `.npy` files representing the input and output sequences. In addition, a `.csv` file containing the normalization statistics used during data generation is produced, along with a representative trajectory of the generated open-loop data.

## (2) Model Training

The outcome of this component is a fully trained Gated Reccurent Unit (GRU) model developed using the open-loop data generated in the previous step. This code takes all files generated during the Open-Loop Simulation stage and outputs a `.pth` file containing the optimized network parameters. Additionally, the code generates training and validation loss evolution plots, FIT index metrics across all test sequences, and graphical comparisons illustrating the model's performance on representative test sequences.

## (3) Controller Training

The outcome of this component is a fully trained GRU controller network developed using a filtered dataset consisting of reference signals that the controller learns to track. This code takes the files generated during the Open-Loop Simulation and Model Training stages and outputs a `.pth` file containing the optimized controller parameters. In addition, it generates the feasible data generation curves depicting the filtered trajectories, training and validation loss evolution plots, FIT index metrics across all test sequences, and graphical results illustrating controller performance on representative test sequences.

## (4) Fine-Tuning

The outcome of this component is the generation of a fine-tuned Model GRU network and Controller GRU network for the target plant. This code takes the pre-trained `.pth` files generated during the Model Training and Controller Training stages and outputs updated `.pth` files containing the optimized parameters obtained during fine-tuning. It also generates feasible data generation curves depicting the filtered trajectories, and training and validation loss evolution plots.

## (5) Closed-Loop Simulation

The objective of this component is to generate a closed-loop comparison between three different control strategies:

1. Traditional IMC-PID
2. Source NN-IMC (without fine-tuning)
3. Fine-Tuned NN-IMC

This code takes the outputs generated by the previous four components and produces a `.csv` file summarizing the performance of the three control strategies using RMSE, steady-state error, and overshoot criteria. In addition, the code generates four figures:

* Reference trajectories used for closed-loop testing
* Output tracking performance compared against reference values and constraints
* Control action comparisons
* RMSE output tracking error comparisons

## Notes

The five components were developed with the activation energy variation case in mind. However, the framework is general and can be adapted to investigate different process parameter variation scenarios with only minor modifications.
